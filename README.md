# Wanderlust Adventures Landing Page

A modern, fully responsive travel landing page built with HTML, TailwindCSS, and vanilla JavaScript.

## Overview

This project is a polished promotional landing page for a fictional travel company called **Wanderlust Adventures**.
It demonstrates strong frontend fundamentals, responsive UI design, smooth animations, and interactive user experience without relying on frameworks.

## Features

* Fully responsive layout
* Modern UI/UX design
* Mobile navigation drawer
* Interactive booking modal
* Animated CTA buttons
* Toast notification system
* Newsletter subscription form
* Smooth scrolling navigation
* Accessible semantic HTML structure
* TailwindCSS styling
* Vanilla JavaScript interactions

## Technologies Used

* HTML5
* TailwindCSS
* JavaScript (ES6)
